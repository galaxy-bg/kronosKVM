# Product Images

The names below belong to the retired CM4 chassis concept and are retained only
as an archive. Do not use them as the active hardware reference. Current
prototype photographs should show the appliance without exposing the underlying
single-board-computer model in operator-facing UI text.

Do not create empty image placeholders. Archived filenames are:

- `kronoskvm-front.jpeg`: SLAVE, DISP, TF, antennas, power input and LED.
- `kronoskvm-rear.jpeg`: HDMI0/1, USB1/2/3 and ETH1/0.
- `kronoskvm-internal.jpeg`: CM4, network hardware, CAM0/1, RTC, display, TF,
  M.2 positions, antennas and fan.

Descriptions must use provisional language for unverified electrical functions.
